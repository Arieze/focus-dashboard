# Ressources tierces

- Compagnon : Free Animated Character Template, Deymoon. Voir `docs/compagnon.md` pour la provenance.
- Notes musicales : Pixel Music Notes / Music Scale Ring, Hamuko27, https://hamuko27.itch.io/pixel-music-notes-free. L'archive originale n'est pas redistribuée.
- Météo : Cooked FX, The Cooked Works. Les planches PNG ne sont pas publiées en tant que ressources autonomes. Pour activer ces effets, obtenez le pack sous sa licence et installez les sept planches utilisées dans `public/weather/cooked-fx/` : env_wind_gust.png, env_sun_rays.png, env_snowfall.png, env_rain.png, env_lightning_flash.png, env_hail_top.png, env_fog.png. Consultez la licence dans `resources/weather/cooked-fx/`. Les pictogrammes restent visibles en leur absence.
- Citations : sélection française, licence source conservée dans `citaitons/LICENSE-source.txt`.

Les logiciels tiers foobar2000, Beefweb et Libre Hardware Monitor ne sont pas embarqués dans ce dépôt.
